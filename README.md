# ATLAS · 建筑典藏馆

交互式 3D 建筑网页，包含埃菲尔铁塔、中国长城、紫禁城和泰姬陵。使用 Three.js r160.1；代码与依赖均在本地，无需 npm 或构建。

## 启动

安装 Python 3 后，Windows 双击 `启动预览.cmd`。或在本目录运行：

```sh
python -m http.server 8770 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8770 。请使用 HTTP，直接双击 index.html 会受到浏览器 ES 模块安全限制。需要支持 WebGL 的现代浏览器。端口被占用时，可更换端口并使用对应网址。

## 操作

- 左侧入口切换建筑，手机上入口位于顶部。
- 拖动旋转，滚轮或双指缩放，支持惯性。
- 透视、正视、俯瞰三种视角与重置视角。
- 自动环绕可暂停；遵循系统减少动态效果偏好，默认暂停。
- 日间 / 夜间展厅；模型说明面板；Esc 关闭说明。

## 模型与许可

四个模型均为本站原创程序化建模，未使用第三方建筑模型或摄影贴图。初步寻找现成模型时 GitHub 公共 API 达到请求限额，未获取可验证许可的适用资产，因此采用程序建模方案。

- 埃菲尔铁塔：四足格构、交叉支撑、四面拱脚、三层平台和天线。省略铆钉、升降机、部分精细杆件。
- 中国长城：山地城墙、垛口、步道、敌楼和森林。原创地形与线路，为明长城典型意象，非实测复原。坐标标注慕田峪附近；总长度指历代遗存总计。
- 紫禁城：压缩后的中轴宫殿序列、重檐屋顶、柱廊、白石台基及围墙。院落、建筑数量、屋顶细节与比例均作艺术化简化，非完整故宫复原。
- 泰姬陵：洋葱穹顶、四角宣礼塔、尖拱凹面、花园和水池。省略石材镶嵌、经文及内部空间。

模型为建筑欣赏与空间研究，不用于测绘、工程或文物复原。模型内所有尺寸为场景单位，介绍数据不作为模型比例标尺。

`vendor/` 中 Three.js、OrbitControls 与 BufferGeometryUtils 使用 MIT 许可证，见 `vendor/LICENSE-three.txt`。Google Fonts 为可选在线字体，断网时回退至系统字体，场景不依赖网络资源。

## 文件

- `index.html` / `style.css`：界面与响应式布局。
- `app.js`：渲染、相机、交互、灯光、切换。
- `models.js`：原创建筑几何，按材质合并重复构件，降低绘制次数。
- `vendor/`：已固定版本的本地依赖。

## 验证

已在 Chromium 浏览器中验证 1440 × 900 桌面、890 × 972 窄桌面与 390 × 844 手机模拟视口。四座建筑均完成渲染和切换，已实际验证鼠标拖动与滚轮缩放，以及三种视角、重置、昼夜切换和说明面板。手机为浏览器模拟验证，未使用实体手机测试。

`preview.png` 与 `preview-mobile.png` 为实际网页截图。相机会根据模型边界和视口比例自动取景；可通过滚轮或双指继续放大查看细部。
